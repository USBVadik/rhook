# Code of conduct

Technical disagreement is expected. Personal attacks, harassment, discrimination, doxxing, and deliberate disruption are not.

When reviewing code or research claims:

- criticize the implementation or evidence, not the person;
- distinguish verified facts from assumptions;
- provide a reproduction for correctness or security claims when possible;
- disclose conflicts of interest;
- do not publish private data or credentials.

The repository owner may remove content or restrict participation when these rules are violated. Report sensitive conduct issues privately to the owner through GitHub rather than escalating them in a public thread.
