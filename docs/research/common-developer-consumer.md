# Common Developer Consumer for retained counterfactual results

The locally accepted Common Developer Consumer applies one CLI and JavaScript
interface to exact retained results from Robinhood Chain and Ethereum Mainnet.
An evidence handle exposes the comparison, named assurance dimensions and
a policy verdict. The admitted case profiles identify exact file hashes.

| Policy | Covered scope |
| --- | --- |
| Recorded review | Both retained cases can be accepted for inspection and recorded-evidence checks. The exact Pair03 route can rerun the JavaScript verify-pack against a supplied trusted block hash. |
| Ethereum consensus | The admitted tools rerun beacon finality, SSZ payload binding and execution ancestry for the exact tx70 capsule. |
| Independent native replay | `UNRESOLVED` in the consumer. The workflow reads and checks evidence without running an EVM. |

The Robinhood retained case is Hookr Pair03 LP50. The Ethereum case is the
[tx70 intervention](ethereum-p2p-counterfactual.md). Both history packages
require their independently reviewed files and trust inputs. The API
does not accept alternate histories under those case IDs.

## Source-only Developer Preview

The source-only package was built and installed locally with Node.js 24,
without runtime npm dependencies. One documented public exercise reads the
[pinned Robinhood Uniswap v4 reference](https://github.com/USBVadik/rhook/blob/493dc5b7a7ab101a2cfcd0be40f13eaa326405a2/examples/robinhood-v4/reference.json.gz).
At transaction **70397227:4** it displays ACTUAL `SUCCESS` and BRANCH
`REVERT`. The example derives a local inspection projection and does not
bundle the reference. Its outcome is `INSPECTED` with assurance
`UNRESOLVED`.

The execution engines, retained verifier binaries and exact historical
Pair03 and tx70 inputs are outside the source-only delivery. The prepared
source scope and local acceptance do not create a hosted service or
arbitrary-history import. See [portable consensus anchoring](ethereum-consensus-anchoring.md)
for the Linux and cold-build limits.
